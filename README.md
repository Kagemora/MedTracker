# MedTracker
Приложение для отслеживания расписания приёма лекарств. Портфолио-проект, демонстрирующий современные подходы к Android-разработке.

# Функциональность

- Расписание приёма — добавление лекарств с указанием дозировки, единицы измерения, дней недели и времени
- Экран на сегодня — отображение ожидающих, принятых и пропущенных доз
- Умные уведомления — уведомления с кнопками «Принял» / «Пропустил» прямо из шторки
- Поиск лекарств — поиск препаратов через OpenFDA API с debounce-задержкой
- История — журнал приёмов, сгруппированный по датам, с фильтром периода (7 дней / 30 дней / 3 месяца)
- Тёмная тема — полная поддержка светлой и тёмной темы, выбор сохраняется через DataStore
- Восстановление после перезагрузки — уведомления автоматически перепланируются после ребута устройства
- Автоочистка — логи старше 90 дней удаляются еженедельно через WorkManager
